## 🎮 핀볼킹

**제작 기간**: 2026.08.31 ~ 2026.09.04 (3일)
**장르**: 플랫포머 (점프킹 레퍼런스)
물리법칙이 적용된 핀볼로 최대한 하늘 높이 올라가는 게임입니다. 벽과 발판을 딛고 최상층을 향해 올라가세요!

## 🕹️ 조작 방법

| 동작 | 조작 |
|---|---|
| 발사 방향/파워 조절 | 마우스 좌클릭 후 드래그 |
| 튕겨서 도약 | 마우스 좌클릭 |
| 종료 조건 | 바닥에서 점점 차오르는 용암과 닿으면 게임 종료 |

## ✨ 주요 기능

- 탄성 충돌, 힘 처리, 마찰, 회전
- 다각형 충돌 처리 (이미지 → 다각형 변환)
- 이미지 마스크 기반 플랫폼 충돌 데이터 자동 생성
- 카메라 이동에 따른 무한 맵
- 규칙 기반 맵 배치 + 플랫폼 플로팅 효과
- 마우스 Pick 기능 (월드 ↔ 스크린 좌표 변환), 발사 방향/강도 표시선
- 시간에 따라 차오르는 용암 — 닿으면 게임 오버
- 현재 높이 / 최고 높이 스코어 UI
- 타이틀 / 게임 / 엔딩 씬 전환
- XAudio2 기반 사운드 매니저
- 충돌 파티클 및 진행 방향 트레일 이펙트

## 👥 제작 (7팀)

- **김승범** — 물리 시뮬레이션, 물 효과, 씬 매니저, 다각형 콜라이더, 맵 배치 생성
- **김종곤** — 텍스처 로더, 무한 맵 생성, 카메라 연동 렌더링, 버튼/점수 UI
- **양효정** — 마우스 입력 관리, Pick 기능, 발사 방향 UI, 높이 스코어 출력, 용암 차오름/게임오버 로직
- **이기현** — 충돌 마스크 제작 및 렌더링, XAudio2 사운드 매니저, 파티클/트레일 이펙트
